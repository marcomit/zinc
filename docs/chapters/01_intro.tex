\chapter{Introduction}

\section{Overview}

Zinc is a statically-typed, compiled systems programming language designed for clarity, performance, and expressiveness.
It compiles native binaries via LLVM and supports generics, receiver functions (methods), a hygienic macro system (WIP), and C interoperability through \zn{foreign} declarations.

\section{Compiler Pipeline}

The Zinc compiler is a single-pass, multi-phase pipeline written in C. The phases run sequentially on each source file:

\begin{center}
\begin{tabular}{lll}
\toprule
\textbf{Phase} & \textbf{Source file} & \textbf{Responsibility} \\
\midrule
Lexical analysis  & \texttt{zlex.c}   & Tokenize source text; keyword hashing \\
Syntax analysis   & \texttt{zparse.c} & Build AST from token stream \\
Semantic analysis & \texttt{zsem.c}   & Type checking, scope \& symbol resolution \\
Code generation   & \texttt{zgen.c}   & Emit LLVM IR; drive lld linker \\
\bottomrule
\end{tabular}
\end{center}

Supporting components:

\begin{description}[leftmargin=4em]
  \item[\texttt{zmacro.c}] Hygienic macro pattern matching and expansion, invoked during parsing.
  \item[\texttt{zmod.c}]   Module resolution: handles \zn{use} imports, multi-file compilation, and AST debug and logs printing.
  \item[\texttt{zmem.h}]   Supports modular allocators.
  \item[\texttt{zmem.c}]   Arena allocator for fast allocations and clean up. It supports also scoped allocations via \texttt{startScope()}/\texttt{endScope()}.
  \item[\texttt{zvec.h}]   Header-only generic dynamic array used throughout the compiler.
  \item[\texttt{zhset.h}]  Header-only string hash set for duplicate detection in symbol tables.
  \item[\texttt{zinc.h}] Header file that contains all definitions for the compilation process.
\end{description}
